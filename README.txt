ВИРТУАЛЬНЫЕ MODBUS-ПРИБОРЫ
=========================

Учебный симулятор шины Modbus: несколько виртуальных приборов на одном
порту, каждый со своим адресом. Управление и визуализация — через
браузерную панель.

УСТАНОВКА
---------
1. Python 3.8 или новее (https://www.python.org).
2. Только если работаете через COM-порт (Modbus RTU):
       pip install pyserial
   В режиме Modbus TCP ничего ставить не нужно.

ЗАПУСК
------
Modbus RTU (настоящий COM-порт, к нему подключён контроллер):
    python modbus_sim.py --port COM3
    python modbus_sim.py --port COM3 --baud 19200
    (на Linux порт выглядит как /dev/ttyUSB0)

Modbus TCP (отладка без железа, мастер подключается по сети):
    python modbus_sim.py --tcp 502

После запуска откройте в браузере:  http://127.0.0.1:8080
В консоли при этом видно, что мастер читает и пишет по шине.
Остановка: Ctrl+C.

КАК ДОБАВИТЬ СВОЙ ПРИБОР
------------------------
Откройте devices.json в любом текстовом редакторе и скопируйте блок
существующего прибора. Поля прибора:

    "addr"   — адрес на шине (1..247, у каждого прибора свой)
    "name"   — название на панели
    "image"  — файл картинки (необязательно), например "img/fan.svg"
    "regs"   — список регистров

Поля регистра:

    "type"   — "holding", "input", "coil" или "discrete"
    "num"    — номер регистра (нумерация с нуля!)
    "widget" — "slider" (аналог), "lamp" (лампочка), "toggle" (тумблер)
               или "bitfield" (битовое слово: регистр input, биты подписаны
               в поле "bits", например "bits": ["Ванна", "Унитаз"])
    "label"  — подпись на панели
    "unit"   — единицы измерения: "%", "°C" и т.п. (для слайдера)
    "min", "max" — пределы слайдера в человеческих единицах
    "scale"  — сколько единиц Modbus в одной человеческой единице:
               scale 10 и 22.5 °C -> по шине поедет число 225
    "init"   — начальное значение в человеческих единицах (необязательно)

Кто чем управляет (человек на панели — это среда, а не прибор):
    holding  — уставка, пишет ТОЛЬКО мастер (функции 06/16); вы смотрите
    input    — датчик: значение задаёте вы ручкой «среды», мастер читает (ф. 04)
    coil     — исполнительное: командует ТОЛЬКО мастер (ф. 05/15); вы смотрите
    discrete — датчик: значение задаёте вы ручкой «среды», мастер читает (ф. 02)

Картинки — любые файлы PNG/JPG/SVG, положите рядом (например в img/)
и укажите путь в "image".
