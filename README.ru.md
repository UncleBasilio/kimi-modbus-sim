Учебный симулятор шины Modbus: несколько виртуальных приборов на одном порту, каждый со своим адресом. Управление и визуализация — через браузерную панель.

---

## Установка

1. Установите **Python 3.8** или новее с [официального сайта](https://python.org).
2. Если планируете работать через COM-порт (**Modbus RTU**), установите библиотеку `pyserial`:
   ```bash
   pip install pyserial
   ```
   *В режиме **Modbus TCP** дополнительно ничего ставить не нужно.*

---

## Запуск

### Modbus RTU (настоящий COM-порт, к нему подключён контроллер)
```bash
python modbus_sim.py --port COM3
python modbus_sim.py --port COM3 --baud 19200
```
*(На Linux имя порта выглядит примерно так: `/dev/ttyUSB0`)*

### Modbus TCP (отладка без железа, мастер подключается по сети)
```bash
python modbus_sim.py --tcp 502
```

### Работа с панелью управления
После запуска откройте в браузере адрес: [http://127.0.0.1:8080](http://127.0.0.1:8080).  
В консоли при этом отображается лог того, что мастер читает и пишет по шине.  
Для остановки симулятора нажмите `Ctrl+C` в терминале.

## Как добавить свой прибор

Откройте файл `devices.json` в любом текстовом редакторе и скопируйте блок существующего прибора.

### Поля прибора

| Поле | Описание |
| :--- | :--- |
| `"addr"` | Адрес на шине (`1..247`, у каждого прибора свой) |
| `"name"` | Название прибора на панели |
| `"image"` | Путь к файлу картинки (необязательно), например `"img/fan.svg"` |
| `"regs"` | Список регистров прибора |

### Поля регистра

| Поле | Описание |
| :--- | :--- |
| `"type"` | Тип регистра: `"holding"`, `"input"`, `"coil"` или `"discrete"` |
| `"num"` | Номер регистра (**нумерация с нуля!**) |
| `"widget"` | Тип элемента на панели: `"slider"` (аналог), `"lamp"` (лампочка), `"toggle"` (тумблер) |
| `"label"` | Подпись на панели |
| `"unit"` | Единицы измерения: `"%"`, `"°C"` и т.п. (для слайдера) |
| `"min"`, `"max"` | Пределы слайдера в «человеческих» единицах |
| `"scale"` | Множитель (сколько единиц Modbus в одной человеческой единице): при `scale: 10` и значении `22.5 °C` по шине передастся число `225` |
| `"init"` | Начальное значение в человеческих единицах (необязательно) |

### Логика управления регистрами
*(Человек на веб-панели выступает в роли «окружающей среды», а не самого прибора)*:

* **`holding`** — уставка: пишет **только мастер** (функции `06`/`16`), вы только смотрите на панели.
* **`input`** — аналоговый датчик: значение задаёте вы ручкой «среды», мастер читает (функция `04`).
* **`coil`** — исполнительный механизм: командует **только мастер** (функции `05`/`15`), вы смотрите.
* **`discrete`** — дискретный датчик: состояние задаёте вы тумблером «среды», мастер читает (функция `02`).

> **Картинки:** Поддерживаются любые файлы `PNG`, `JPG` или `SVG`. Положите их в папку рядом со скриптом (например, в `img/`) и укажите относительный путь в поле `"image"`.
