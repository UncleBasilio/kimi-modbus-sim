An educational Modbus bus simulator: multiple virtual devices sharing a single port, each with its own address. Control and visualization are handled through a web browser dashboard.

---

## Installation

1. Install **Python 3.8** or newer from the [official website](https://python.org).
2. If you plan to work via a serial COM port (**Modbus RTU**), install the `pyserial` library:
   ```bash
   pip install pyserial
   ```
   *No additional packages are required for **Modbus TCP** mode.*

---

## Running the Simulator

### Modbus RTU (real COM port connected to a controller)
```bash
python modbus_sim.py --port COM3
python modbus_sim.py --port COM3 --baud 19200
```
*(On Linux, the port name looks like `/dev/ttyUSB0`)*

### Modbus TCP (hardware-free debugging, master connects over the network)
```bash
python modbus_sim.py --tcp 502
```

### Using the Control Dashboard
Once started, open your browser and go to: [http://127.0.0.1:8080](http://127.0.0.1:8080).  
The console window displays a live log of everything the Modbus master reads and writes on the bus.  
To stop the simulator, press `Ctrl+C` in the terminal.

## How to Add a Custom Device

Open `devices.json` in any text editor and copy an existing device block.

### Device Fields

| Field | Description |
| :--- | :--- |
| `"addr"` | Bus address (`1..247`, must be unique per device) |
| `"name"` | Display name on the dashboard |
| `"image"` | Path to an image file (optional), e.g., `"img/fan.svg"` |
| `"regs"` | List of device registers |

### Register Fields

| Field | Description |
| :--- | :--- |
| `"type"` | Register type: `"holding"`, `"input"`, `"coil"`, or `"discrete"` |
| `"num"` | Register address/number (**zero-based indexing!**) |
| `"widget"` | Dashboard UI element: `"slider"` (analog), `"lamp"` (indicator), or `"toggle"` (switch) |
| `"label"` | Label text on the dashboard |
| `"unit"` | Measurement units: `"%"`, `"°C"`, etc. (for sliders) |
| `"min"`, `"max"` | Slider range limits in human-readable units |
| `"scale"` | Multiplier (how many Modbus units equal one human unit): with `scale: 10` and `22.5 °C`, the value `225` is sent over the bus |
| `"init"` | Initial value in human-readable units (optional) |

### Register Control Logic
*(The user on the web dashboard acts as the "physical environment", not the device itself)*:

* **`holding`** — Setpoint: written **only by the master** (functions `06`/`16`); read-only monitoring on the dashboard.
* **`input`** — Analog sensor: you set the value using the "environment" slider; the master reads it (function `04`).
* **`coil`** — Actuator: controlled **only by the master** (functions `05`/`15`); read-only monitoring on the dashboard.
* **`discrete`** — Digital sensor: you set the state using the "environment" toggle; the master reads it (function `02`).

> **Images:** Any `PNG`, `JPG`, or `SVG` files are supported. Place them in a folder next to the script (e.g., `img/`) and specify the relative path in the `"image"` field.
